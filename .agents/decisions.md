# Decisions (ADRs)

- **ADR-001 Next.js 16 App Router, Tailwind v4, hand-written shadcn-style UI.** The spec asks for 14+. Atoms are
  written locally (no Radix yet) to keep JS small; add Radix/shadcn primitives only when a component needs focus
  trapping (dialogs, menus).
- **ADR-002 No Redux yet.** The template's state policy says no global state until required. Server data = RSC fetch
  plus TanStack Query (client-only suggestions); UI state is local. Add Redux Toolkit when a real cross-tree store appears.
- **ADR-003 No `cacheComponents`.** The create-next-app default enabled it; it forbids `revalidate`/`dynamicParams`
  route config and changes fetch semantics. The spec's ISR + tag model uses classic caching, so it is off.
- **ADR-004 The API contract is proposed by the frontend.** The spec lists endpoints (section 12) but not response
  bodies. `src/lib/api/types.ts` defines them; backend Pydantic schemas must match (or change that file in the same PR).
  Also assumed: `GET /papers?sort=latest`, `GET /search` returns `facets` + `suggestions`,
  `GET /seo/sitemap/{type}?page=` returns `{items:[{path,lastmod}], total_pages}`,
  `POST /reports` accepts `{reason, email, details}`. `NEXT_PUBLIC_API_URL` includes `/api/v1`.
- **ADR-005 Search is server-rendered.** `/search` reads `searchParams` and fetches with `no-store`, so it works
  without JS and filters are plain GET forms. Only the suggestion dropdown is client-side.
- **ADR-006 Sitemaps are route handlers**, not `app/sitemap.ts`, to match the spec URLs
  (`/sitemap.xml` index, `/sitemaps/{type}/{n}.xml`).
- **ADR-007 Degraded rendering.** Home and `/universities/{university}` catch API failures and render empty states with a
  1h revalidate; other pages let errors reach `error.tsx` so a bad render is never cached. The pipeline should also
  send `paths` to `/api/revalidate` for these two pages.
- **ADR-008 Cloudflare deploy is pending.** `@opennextjs/cloudflare`, `wrangler.jsonc` and the R2/KV incremental
  cache are not added yet; verify Next 16.4 support first and document unsupported features here.
- **ADR-009 Auth.** `@supabase/ssr` cookie session. `src/proxy.ts` gates `/admin /account /bookmarks /downloads
  /upload`; with Supabase unconfigured it redirects to `/login` (fail closed).
- **ADR-010 No root `loading.tsx`.** With a root loading boundary Next streams the response, so `notFound()` returned HTTP 200 (a soft 404, bad for SEO). The skeleton now lives only in `/search/loading.tsx`; all other pages return real 404s.
- **ADR-011 TypeScript stays on 5.9.** TypeScript 7 is out but `typescript-eslint` (used by `eslint-config-next`) does not support it yet. Revisit when it does. eslint 10 and @types/node 26 are current.
- **ADR-012 Backend integration verified.** The proposed contract in `types.ts` (ADR-004) is now implemented by the FastAPI repo (`app/schemas/public.py`); built and smoke-tested against it with demo data. Renamed paper slugs 301 via `GET /redirects/paper/{slug}`; IndexNow key is served at `/indexnow-key.txt`.
- **ADR-013 Auth proxy (BFF).** Signed-in browser calls go to `/api/backend/*`, which adds the Bearer token from the HttpOnly session cookie. Only `me, uploads, admin, reports, contact, bookmarks` are forwardable, writes must be same-origin, redirects (signed file URLs) are passed through. Header user state is client-side (`useMe`) so public pages stay static/ISR.
- **ADR-014 Developer login.** Without a Supabase project the backend mints tokens (`POST /dev/login`, `DEV_AUTH=true`, never in production) and the site stores it in an HttpOnly cookie. Hard-disabled when `NODE_ENV=production`. `getAccessToken()` always calls `cookies()` first so private pages are never prerendered "signed out".
- **ADR-015 Port 3010** (not 3000) so the site can run next to other local apps.
- **ADR-016 PDF preview** uses the browser viewer in an `<iframe>` (`?inline=true`, not counted as a download) instead of bundling pdf.js: zero JS cost until the visitor asks, works on mobile.
- **ADR-017 Toasts** use design tokens, not Sonner's rich colours (those failed WCAG AA contrast in axe).
- **ADR-018 Link-only mode.** The backend can run without storing files (`STORE_FILES=false`). The paper page then shows "View on original site" (new tab, `nofollow noopener`), hides the PDF preview, stays indexable, and `/upload` shows "Uploads are paused" (from `GET /features`, cached 60 s). Supabase's new "publishable" key is accepted as `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (or the old ANON name).
- **ADR-019 JSON API layer and no tests.** Public reads go through `src/app/api/{courses,papers,search,me}` (thin proxies over the backend with cache headers); the browser calls them via `src/services/queries.ts` and TanStack Query hooks (`src/hooks/use-catalog.ts`). Server-rendered `initialData` keeps SEO/no-JS content; the client refetches on mount. All automated tests were removed on purpose (they slowed work down); verify changes with `npm run check` and by hand.
- **ADR-020 Comprehensive Domain Taxonomy for Papers & Exams.** Extended exam and paper display to support multiple educational domains: University, Competitive Exams, and School Boards. Competitive exams are grouped by year; university courses are categorized by degree, semester, or annual scheme; school boards are categorized by standard/year. Built `ExamsCatalogView` (`src/components/shared/exams-catalog-view.tsx`) with domain filter tabs ("All", "University", "Competitive Exam", "School Board") to organize 3,000+ papers seamlessly.
- **ADR-021 Dedicated Download Pipeline & Live PDF Preview Flow.** Redesigned the paper download user journey. Replaced immediate blind downloads with a dedicated step page at `/papers/[slug]/download` powered by `DownloadManager` (`src/components/shared/download-manager.tsx`). Shows file metadata, session/year, subject, a 3-second animated countdown with progress bar, automatic background download stream trigger, confirmation success card, and an embedded live PDF preview frame below.
- **ADR-022 Instant Search Dropdown, 800ms Debounce, Shimmer Loading & Local History.** The search bar (`src/components/shared/search-bar.tsx`) opens suggestions immediately on focus or input. Implemented an 800ms debounce to avoid overwhelming backend APIs while typing, dynamic skeleton shimmer placeholders during API fetches, and persistence of recent searches in `localStorage` (`notes_recent_searches`) with one-click clear.
- **ADR-023 OpenNext / Cloudflare `__name is not defined` Runtime Resolution.** Resolved `Uncaught ReferenceError: __name is not defined` on Cloudflare Pages/Workers deployed with `@opennextjs/cloudflare`. The root cause was esbuild injecting `__name(fn, "name")` into `next-themes` inline script evaluated in global browser scope. Fixed by configuring `"keep_names": false` in `wrangler.jsonc` and adding an inline polyfill fallback script inside the `<head>` in `src/app/layout.tsx`.
- **ADR-024 Client Query Cache & Waterfall Elimination.** In `src/hooks/use-catalog.ts`, adjusted `staleTime` from 0 to 5 minutes (`300_000` ms) and removed `refetchOnMount: "always"`. Because Next.js server-side rendering already supplies fresh catalog and paper data, this prevents redundant immediate client network requests on initial page load.
- **ADR-025 Canonical Contact and DMCA Designation.** Standardized contact email to `thecodinggiant@gmail.com` across all site footers, copyright notices, takedown requests, contact forms, and security disclosures.
- **ADR-026 Admin Table Layout & Input Standardization.** Standardized all admin search forms, filter selectors, and submit triggers to uniform `h-11` (44px) heights. Added inset search icons with `pl-10` padding. Fixed table squishing by setting `min-w-[54rem]` on `DataTable` with horizontal scrolling (`scroll-slim`) and replacing `break-all` on URLs with truncated mono strings.
- **ADR-027 Admin Instant Sync Trigger via GitHub Actions.** Created `InstantSyncButton` (`src/components/admin/instant-sync-button.tsx`) integrated globally into admin navigation, overview, and SEO headers. Calls `POST /api/backend/admin/sync/dispatch` to trigger `daily-sync.yml` on GitHub Actions, with automated fallback to in-process sync.
- **ADR-028 Dynamic Sitemap URL Resolution & Google Site Verification.** In `src/app/sitemap.xml/route.ts` and `src/app/sitemaps/[type]/[file]/route.ts`, dynamically derived `baseUrl` from incoming `new URL(req.url).origin` at request time so all 4,139+ paper URLs emit production domain `https://notesandpapers.dpdns.org/...` rather than build-time `localhost:3010`. Embedded Google site verification tag in `src/app/layout.tsx`. Configured custom domain route and environment variables in `wrangler.jsonc`.
- **ADR-029 Googlebot Compliance & Robots.txt Cleanup.** Removed the non-standard `Host:` directive from `src/app/robots.ts` to clear Google Search Console's "Rule ignored by Googlebot" warning.
- **ADR-030 High-Impact Paper Download Hero Card.** Completely redesigned the paper download action card in `src/components/shared/paper-page.tsx`. Replaced the low-contrast, awkward box with a high-impact neo-brutalist hero section featuring a top contrast header ribbon with verified vault and watermark-free badges, matched `variant="outline"` bookmark and report buttons, rich trust indicators (Fast CDN, Print-Ready Vector, 100% Free), a bold `h-14` CTA button, and online preview jump link.
- **ADR-031 Sanitized Live Preview & Off-Site Link Scrubbing.** Implemented `src/lib/sanitize-preview.ts` to inspect and strip competitor crawler links (e.g. `a2zsubject.com`, `uroroonline.com`, `pyqonline.com`, `rtuonline.com`) from paper titles, download buttons, and PDF preview wrappers, ensuring all live links resolve to canonical internal routes.
- **ADR-032 Minimum 16px Input Font Size.** Enforced strict minimum `16px` (`text-base` / `text-[16px]`) across all text inputs, textareas, and selects sitewide (search bar, contact form, takedown form, login/signup, upload form, admin filters) to prevent iOS Safari and Android Chrome from automatically zooming in and breaking responsive layouts upon focus.
- **ADR-033 Sequential Paper Numbering & Section Paper Synchronization.** When multiple papers exist for a subject or year (e.g. shifts, schemes, or variants), `PaperCard` and `PaperList` now render explicit `Paper #{index + 1}` sequence badges. Fixed out-of-sync total paper counts on `exams/[slug]/page.tsx` (`Math.max(exam.paper_count ?? 0, totalSectionPapers)`) and synchronized section count badges. Added `BOARD_CLEAN_NAMES` and `cleanExamTitle` in `src/lib/exam-categories.ts` to normalize crawler names (e.g., `rajasthan-4th-grade` -> "Rajasthan 4th Grade", `uni-rajasthanboard` -> "RBSE Board (Rajasthan BSER)").
- **ADR-034 School & State Education Boards First-Class Integration.** Transformed the home page "Browse by University" section into "Browse by university & school boards", co-locating major boards (RBSE, CBSE, UP Board, ICSE, MP Board, CG Open School) with universities in a 4-column neo-brutalist grid with filter tabs (`All`, `Universities`, `School Boards`). Added a dedicated boards section in `src/app/universities/page.tsx` with clickable class/stream tags.
- **ADR-035 In-Flight Request Coalescing & Search Debouncing.** In `src/services/queries.ts`, wrapped `getJson` in an in-flight request deduplication map that coalesces identical concurrent GET requests into a single promise. Created `useDebounce` hook (`src/hooks/use-debounce.ts`) applied to global search (450ms) and catalog search (250ms) with animated shimmer skeletons. Tuned TanStack Query defaults to `staleTime: 5m`, `gcTime: 15m`, and `refetchOnWindowFocus: false`.
- **ADR-036 Googlebot Crawlability & Brand Schema Standardization.** Fixed Google Search Console "hidden from public indexing" and "DigitalPlat Domain" snippet naming:
  1. Removed conditional `noindex` directives across `universities/[university]`, `exams/[slug]`, course, term, and subject pages, replacing them with `index: true, follow: true` and Googlebot rich snippet directives (`max-snippet:-1, max-image-preview:large`) in `src/lib/seo.ts`.
  2. Placed `WebSite` JSON-LD schema into `<head>` with explicit `name: "Notes & Papers"`, `alternateName: ["Notes & Papers", "NotesAndPapers", "Notes and Papers"]`, `applicationName`, and `og:site_name`.
  3. Added root-level 192x192 PNG (`/icon-192.png`), `/favicon.ico`, `/icon.png`, and `/apple-touch-icon.png` in `public/` and linked them explicitly in `<head>` to satisfy Google Search's multiple-of-48px favicon requirement.
- **ADR-037 Social Community Engagement Popup.** Created `CommunityPopup` (`src/components/shared/community-popup.tsx`) that slides in from the bottom with links to Telegram ([@notes_and_papers](https://telegram.me/notes_and_papers)) and Instagram ([@exam.notes.and.papers](https://www.instagram.com/exam.notes.and.papers?exln=cmp5ZHRlaWVtY2Nz)), equipped with a 10-second auto-dismiss timer, an immediate dismiss button, and session-aware re-display logic.
- **ADR-038 Technical SEO & On-Page Hardening (Seobility Audit Resolution).** Resolved all findings from Seobility on-page audit:
  1. **HTTP -> HTTPS & WWW -> Non-WWW 301 Redirects:** Configured automatic 301 Permanent Redirects in `src/proxy.ts` middleware for requests with `x-forwarded-proto: http`, `cf-visitor: {"scheme":"http"}`, or host starting with `www.`.
  2. **Strict-Transport-Security (HSTS):** Added `Strict-Transport-Security: max-age=31536000; includeSubDomains; preload` header in `next.config.ts`.
  3. **Meta Description Character Budget:** Shortened homepage meta description from 176 characters (1015 px) to 141 characters (< 1000 px limit) across `src/app/page.tsx` and `src/app/layout.tsx`. Tightened general clipping ceiling in `src/lib/seo.ts` to 150 characters.
  4. **Image Alt Attributes:** Added descriptive `alt="Notes & Papers Logo"` to both site header and site footer logo `<Image>` components, and fallback alt text for dynamic avatars.
  5. **H1 Content Echoing:** Aligned leading hero paragraph in `src/app/page.tsx` to verbatim include `previous year papers` and `turn study into success` directly below `<h1>`.
  6. **Internal Link Normalization:** Replaced internal tag URLs in `POPULAR_SCHOOL_BOARDS` (which previously pointed to `/search?q=...`) with clean static board routes (`/exams/${b.slug}`) and added unique `aria-label` attributes to prevent repetitive anchor text warnings.
- **ADR-039 Google Sitelinks Schema, 48px+ Favicon Strictness, and UNIRAJ/UOR Keyword Ingestion.**
  1. **Google Sitelinks Schema:** Added `@graph` containing `WebSite`, `Organization`, and an array of `SiteNavigationElement` entries in `src/app/layout.tsx` linking directly to primary course landing pages (UNIRAJ B.Com, B.Sc, BCA, B.Ed, B.A, RTU B.Tech, RBSE, CBSE, UPSC) to trigger organic sitelinks in Google Search results.
  2. **Favicon Strict Compliance:** Removed undersized `16x16` and `32x32` link declarations from `metadata.icons` (which caused Googlebot-Image to reject the favicon based on Google's strict "Do not provide a 16x16px favicon; must be 48x48+" rule). Placed `src/app/icon.png` (192x192) and `src/app/apple-icon.png` (180x180) for native App Router static metadata serving.
  3. **High-Intent Regional Keyword Targeting:** Enriched `src/lib/seo.ts` (`courseMeta`), `src/app/universities/[university]/page.tsx`, and backend `app/ingest/seo_meta.py` with high-volume search phrases students actually query: `UNIRAJ`, `UOR`, `RU Jaipur`, `Rajasthan University`, and `RTU Kota`.
- **ADR-040 Scrollbar UX Normalization & Admin Sidebar Scrollbar Elimination.**
  1. **Global Scrollbar Modernization:** In `src/app/globals.css`, removed the awkward, clunky Windows stepper arrow buttons using `::-webkit-scrollbar-button { display: none !important; }`. Narrowed scrollbar width from 14px to a modern 8px pill thumb with transparent track and smooth gold hover state. Added `.no-scrollbar` cross-browser utility.
  2. **Admin Sidebar Scrollbar Removal:** In `src/app/admin/layout.tsx`, removed `scroll-slim` and applied `no-scrollbar [scrollbar-width:none] [-ms-overflow-style:none] [&::-webkit-scrollbar]:hidden` to the `<aside>` sidebar container so that no scrollbar is displayed in the admin panel while maintaining mouse-wheel scrolling capability.
- **ADR-041 Support Chat Console & Helpdesk Architecture.** Replaced the static `/admin/reports` table with a dedicated two-pane Helpdesk Chat Console (`SupportChatConsole` in `src/components/admin/support-chat-console.tsx`). Features:
  1. **Two-Way Thread Grouping:** Isolates student inquiries strictly by verified email/ticket ID so multiple student tickets never merge into one thread.
  2. **Window Jump Elimination:** Replaced whole-page `scrollIntoView()` with inner-container scrolling `chatContainerRef.current.scrollTop = chatContainerRef.current.scrollHeight`.
  3. **Real-Time Unread Indicators:** Implemented a 30s background poll in `AdminNav` with a pulsing red counter badge, and visual unread indicator dots on individual student threads in the console.
  4. **Student Chat Widget (`SupportChat`):** Student-facing study companion in `src/components/shared/support-chat.tsx` with animated Notey avatar, automated ticket submission, and manual status refresh.
  5. **Deduplication & Hygiene:** Added `sanitizeMessages` to deduplicate greetings and tour completion alerts on mount, and added a one-click "Clear Chat" history action.
  6. **Hydration Warning Fix:** Refactored `NoteyAvatar` (`src/components/account/notey-avatar.tsx`) to render semantic `<div>` when `onClick` is omitted, eliminating invalid HTML `<button>` inside `<button>` errors.
- **ADR-042 Academic Hub 4-Card Hierarchy & Distinct Badging.** Standardized the home page "All (Universities & Boards)" section cards in `src/components/shared/home-sections.tsx` into exact sequence:
  1. **Rajasthan Technical University (RTU)**
  2. **Rajasthan University (UNIRAJ)**
  3. **School Boards Hub** (RBSE, CBSE, UP Board, ICSE, MP Board, All School Boards)
  4. **Other Exams** (Competitive exams: SSC, SBI Clerk, UPSC, GATE, NEET)
  Differentiated card icons by using `<School />` for school boards and `<Award />` for competitive examinations.
- **ADR-043 Next.js BFF Proxy Enforcement for Browser Support APIs.** Browser-side client code must never invoke cross-origin Render backend endpoints directly using `apiFetch`, as Render blocks `localhost:3010` under strict production CORS. All client support calls route through same-origin BFF proxy (`bff("contact", ...)` -> `/api/backend/contact`), which forwards server-to-server. Also removed `status=all` from queries to ensure 100% compliance with FastAPI's strict literal enum validation.
- **ADR-044 Pure 1-on-1 Live Chat (Removal of Ticket UI & Robot Auto-Replies).**
  Replaced the ticket-based support chat model (`Ticket #...`, `open`/`resolved` states, automated robot confirmations, localStorage reply caching) with a dedicated two-way 1-on-1 conversation backed by `chat_conversations` / `chat_messages`:
  1. **Zero Duplicate Conversations:** Browser guests receive a stable `guest_id` (`np_chat_guest_id_v1`) sent alongside optional name/email or logged-in account details so repeated messages always append to the same thread.
  2. **Zero Ticket Clutter:** Eliminated ticket IDs, Resolve buttons, and automated "Got it! / Tour completed!" message spam from both `SupportChat` and `SupportChatConsole`.
  3. **Live Two-Way Polling & Accurate Unread Counters:** Added `"chat"` to BFF `ALLOWED` segments (`src/lib/bff.ts`). Admin console polls `/admin/chats` (8s) and open thread (4s); `AdminNav` polls `/admin/chats/unread` (15s) and listens to `np:admin-chat-updated`; guest chat polls `/chat` (5s when open, 25s if started when closed).
  4. **Separated Paper Reports:** `reports` remains solely for broken PDF reports & DMCA claims under the `"Paper Reports"` view (`?view=table`).
